一、应用沙箱存储规范

目录生命周期 & JSAPI 对照

目录 系统清理 用户清理 卸载行为 推荐用途 可用 API
files 永不 清除应用数据 删除 凭证、配置、小 DB file / fastlz / tar
mass 永不 文件管理器 删除 图片、音视频、文档 file / fastlz / tar / media
cache 空间不足自动 一键清缓存 删除 缩略图、临时资源 file / request.download
tmp 退出可能清理 无 删除 日志、解压中间 fastlz 输出
preferences 永不 清除应用数据 删除 键值、主题、开关 storage.set/get
/sdcard/internal/
共享		 永不 无 不删除 跨应用字体/插件 仅 tar.untar
res:// — — 随 rpk 销毁 只读静态资源 file 只读 / image / audio
tmp:// 系统 重启清空 — — 系统内部临时 ❌ 业务禁止
🔐 核心规则：常规 file/fastlz/statvfs → internal://xxx 映射到 /sdcard/internal/包名/xxx（应用隔离）
⚠️ tar.untar 特殊：internal://xxx 映射到 /sdcard/internal/（无包名，全局共享）
🚫 安全红线：共享目录多应用可读写，必须防护路径遍历攻击；fastlz/tar 源路径禁止使用 tmp://
🔒 网络根证书约束（手表端）：
手表系统仅信任以下根证书，若您的服务端证书由其他 CA 签发，或使用自签名证书，网络请求将直接失败。
✅ 信任列表： ISRG Root X2 · GlobalSign Root CA · DigiCert Global Root G3 · DigiCert Global Root G2
请确保您的服务端证书链源自上述根证书之一，否则将无法正常建立 HTTPS 连接。

⚠️ 系统存储 API 单位勘误（非应用沙箱）：
针对 device.getTotalStorage 和 device.getAvailableStorage 接口，文档标注返回值的 totalStorage / availableStorage 单位为 Byte（字节），但实际系统返回值为 KB（千字节）。
例如返回 10240 实际代表 10240 KB（约 10 MB），而非 10 KB。
⚠️ 注意：statvfs 等应用沙箱文件系统接口的单位是 正确的（按文档说明处理），请勿混淆。
📌 权限规范：硬件/跨应用接口必须在 manifest.json 的 permissions 节点声明，如 "watch.permission.LOCATION"。
📌 Feature 声明：绝大部分接口需在 features 中声明才能调用，详见各接口文档。

四、BlueOS 完整开发规范

1. 标准项目工程目录

├── scripts/ ├── src/ │ ├── assets/ # 全局静态资源（图片/字体/样式） │ │ ├── images/ │ │ └── styles/ │ ├── pages/ # 业务页面目录 │ │ ├── Demo/ # 首页 │ │ │ └── index.ux │ │ └── DemoDetail/ # 详情页 │ │ └── index.ux │ ├── widgets/ # 智慧卡片（标准卡/轻卡） │ ├── widgetProvider/ # 轻卡数据服务脚本 │ ├── i18n/ # 多语言资源 │ ├── app.ux # 全局入口（生命周期 + 公共工具） │ └── manifest.json # 项目核心配置 ├── jsconfig.json └── package.json

2. manifest.json 核心配置

字段 必填 说明
package ✅ 唯一包名 com.company.module
name ✅ 桌面名称，≤6 汉字
icon ✅ 114×114 无白边正方形
versionName / versionCode versionCode ✅ 版本名如 1.0；版本号每次上架 +1
features ❌ 声明使用的 JS 接口，不声明无法调用
permissions ❌ 硬件/敏感权限（定位、录音、蓝牙等）
router ✅ entry 首页、pages 页面、widgets 卡片路由
config.designWidth ✅ 页面适配基准宽度，推荐 466
appCategory ✅ 应用分类：utilities / sport / music 等
background.features 后台应用 ✅ 允许后台运行的能力（音频/定位等）
supportsRtl ❌ 是否支持 RTL 阿拉伯布局
// manifest 最小示例 { "package": "com.example.demo", "name": "工具助手", "icon": "/assets/images/logo.png", "versionName": "1.0", "versionCode": 1, "appCategory": ["utilities"], "config": { "designWidth": 466 }, "router": { "entry": "Demo", "pages": { "Demo": {"component":"index"} } }, "features": [{"name":"blueos.storage.file"}], "permissions": [{"name":"watch.permission.LOCATION"}] }

5. 卡片（Widget）开发规范

标准卡 (js)

  • ✅ 完整 JS 逻辑
  • ✅ 支持 UI 组件 + 动画
  • ✅ 自主数据刷新
  • 📌 适用：复杂交互卡片

轻卡 (lite)

  • ❌ 无 JS 脚本

8. 屏幕适配方案

单位/方式 说明
px 自适应单位，跟随 designWidth 等比缩放
dp 绝对物理尺寸，不受屏幕比例影响
媒体查询 区分方形/圆形手表、横竖屏、分辨率
资源匹配 res-xxx.json 配置不同设备图片资源
$device.deviceType JS 中判断 watch-square / watch-round

9. 性能优化强制规范

  1. 响应式精简：非静态数据不放入 data，减少 Proxy 监听开销
  2. 资源释放：onDestroy 必须清除定时器、事件订阅、音频实例，防止内存泄漏
  3. 列表渲染：必须使用 tid 唯一标识，提升 Diff 复用性能
  4. 条件指令：高频切换用 show，低频销毁用 if
  5. CSS 选择器：禁止多层后代选择器，降低渲染耗时
  6. 图片资源：尺寸与显示区域严格匹配，避免超大图占用内存
  7. 组件抽象：单页面自定义组件 ≤ 3 个，简单组合不抽象

10. 国际化 i18n & RTL

  • 多语言：src/i18n/zh-CN.json / en.json，通过 $t('path') 读取
  • 单复数：$tc('path', count) 支持复数形态
  • RTL 布局：开启 supportsRtl，使用 margin-inline-start 等逻辑样式
  • 镜像：mirroring: auto 让图片在 RTL 下自动水平翻转
  • 语言切换回调：onConfigurationChanged 监听 event.type === 'locale'

11. 权限管理速查

权限名 对应能力 错误码
watch.permission.LOCATION 地理位置 400 / 402
watch.permission.STEP_COUNTER 计步传感器 400 / 402
watch.permission.DEVICE_INFO 设备信息（ID/序列号） 400 / 402
watch.permission.RECORD 录音 400 / 401 / 402
watch.permission.BLUETOOTH 蓝牙 400 / 402
watch.permission.READ_HEALTH_DATA 健康数据（心率/血氧） 400 / 402
watch.permission.PLACE_CALL 拨打电话 400 / 402
watch.permission.SEND_MESSAGES 发送短信 400 / 402
📌 权限申请：在 manifest.json 的 permissions 数组中声明，运行时系统会弹出授权弹窗。
📌 错误码：400 = 用户拒绝，401 = 后台不允许，402 = 未声明权限。
